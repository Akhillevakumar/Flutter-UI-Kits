# Flutter UI Kits (Monorepo)

This repository contains Flutter UI kit experiments and is now organized as a **Melos monorepo**.

## Workspace layout

- `apps/flutter_ui_kits` — the existing Flutter UI Kits application.

## Quick start

1. Install Melos:

   ```bash
   dart pub global activate melos
   ```

2. Bootstrap dependencies for all workspace packages:

   ```bash
   melos bootstrap
   ```

3. Run the app:

   ```bash
   cd apps/flutter_ui_kits
   flutter run
   ```
